About This Project

Tidal Playlist Converter is a web application that allows you to export and convert playlists from Tidal to other music streaming platforms.

This project was created over five weeks, for the class CSCI 3308 Software Development at the University of Colorado, Boulder.

APIs Used:

  • Spotify
  • Tidal
