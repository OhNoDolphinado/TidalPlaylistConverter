CSCI 3308 · CU Boulder · 2026

Built for music lovers,
by music lovers

TidalConverter is a web application that lets you seamlessly migrate your Spotify playlists to Tidal. Built over five weeks as a capstone project for Software Development Methods & Tools at the University of Colorado Boulder.

Tech Stack

Under the hood

🟢
Node.js + Express
REST API server with session-based authentication and middleware-driven architecture.
🐘
PostgreSQL
Relational database for users and playlist conversion history.
🐳
Docker
Containerised development and deployment using Docker Compose.
🔐
bcrypt
Password hashing with industry-standard salt rounds. Credentials are never stored in plaintext.
🧪
Mocha & Chai
Automated test suite covering auth endpoints and server health checks.
🌐
Vanilla JS
No frontend framework needed — fast, lightweight, and easy to maintain.
